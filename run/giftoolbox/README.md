# 表情包工具箱

沿用项目插件加载、消息组件和 YAMLManager 配置热重载，不需添加 Python 依赖。
支持群聊及私聊，可直接发送图片、回复图片/动图、引用合并转发，或使用 @对象头像。

常用指令：
- 表情包帮助：帮助图片，绘图失败时回退文本。
- 变速 2x / 变速 30fps、倒放、分解。
- 裁剪 3x4 / 裁剪 2x2 边距10、做旧 5、线稿。
- 表情合成 0.5：按消息内的媒体顺序合成动图。
- 视频转gif 0s-5s 帧率12 缩放0.4：复用项目已有的 ffmpeg；未安装时仅此功能
  提示不可用，不影响其他功能。无需 imageio。

config.yaml 可修改开关、触发词、输出格式和回复文案；commands 使用列表，复制
一个指令项并保留 action 即可添加同一功能的别名，项目更新时会保留用户的整份指令列表。
兼容初始版本的字典配置。图像算法在 service/core.py，帮助渲染在
service/help_image.py，事件与媒体解析在 giftoolbox.py。

处理边界为代码内的安全常量，无需新增配置：同时最多两个媒体任务，忙时立即提示，
不无限排队；单文件及合成输入总量最多 32 MiB，最多解析 100 个媒体；图片最多
400 万像素、500 帧、累计 6400 万解码像素；网格最多 100 格。视频最多截取
10 秒、最长边 512 像素，FFmpeg 45 秒超时，视频解码不扫描截取区间之前的帧。
这些限制用于避免线程池和内存被单次请求占满，超限返回可读错误。

CPU 与文件读写在线程执行；下载使用异步流式读取并限制体积。任务取消时等待正在
执行的线程结束后再释放任务名额、删除临时视频。发送索引串行写入并原子替换，缓存
30 分钟后按需清理。拆帧/裁剪通过项目原生 Node 消息按批发送。
