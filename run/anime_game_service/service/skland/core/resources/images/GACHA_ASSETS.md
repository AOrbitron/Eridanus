# 抽卡图素材来源

本目录 `gacha_*` 文件复制自 [BeyondUID](https://github.com/baiqwerdvd/BeyondUID)，参考提交 `95ba169`，对应 `BeyondUID/beyonduid_gachalog/texture2d/`（包括其中 `bg/bg4.jpg`）。文件名增加 `gacha_` 前缀，未修改原始图片。

包含 `title.png`、`card_bg.png`、`yellow_card.png`、`sg_bg.png`、`sg6_fg.png`、`up_tag.png`、`A.png`、`frame_fg.png`、`bg/bg4.jpg`。版式参考同仓库 `beyonduid_gachalog/draw_img.py`，用于用户要求的原项目绘图风格适配。

上游 `pyproject.toml` 声明 `GPL-3.0-or-later`。游戏角色、武器及游戏标识等素材的权利归相应权利人；本说明记录来源，不变更其权属。角色/武器头像与 UP 数据表使用上游资源仓库的对应路径按需获取，绘图不依赖本机参考仓库路径。
